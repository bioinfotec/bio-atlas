# BioAtlas 生物学学习图谱

一个用 Next.js App Router、React 和 Tailwind CSS 搭建的中文学习网站。首页保留五个可展开的阶段，学习者可以按顺序阅读，也可以从知识库搜索英文术语，直接进入对应的中文讲解。

## 本地开发

使用 Node.js 20.9 或更高版本，在项目目录运行以下命令。

```powershell
npm ci
npm run dev
```

打开终端打印的本地地址。`npm run build` 会生成可部署到静态托管服务的 `out/` 目录。

## 课程设计

| 阶段 | 模块 | 知识点 | 学习目标 |
| --- | ---: | ---: | --- |
| 细胞生物学 | 6 | 40 | 把细胞结构与运输、分裂和信号传递联系起来 |
| 分子生物学 | 7 | 54 | 解释序列如何携带和传递信息 |
| 遗传学与基因调控 | 6 | 45 | 将表型、遗传变异与调控证据联系起来 |
| 生物化学与细胞功能 | 6 | 44 | 从分子相互作用理解酶活性、能量与代谢 |
| 生物信息学与组学分析 | 7 | 56 | 从实验设计出发，判断统计结果支持哪些生物学结论 |

## 增加知识点

`content/` 中每个文件对应一个阶段，文件内按模块组织。往指定模块的 `lessons` 数组增加一行即可。每行依次是中文标题、英文术语、概念讲解、自测题和参考答案。新增模块还需填写 `title`、`source` 和指向相关阅读的 `url`。例如，下面是一条可添加的学习卡。

```json
["质体的分化", "Plastid differentiation", "质体可在发育过程中分化为不同类型。例如，地下生长的块茎见光后，部分质体可形成含叶绿素的叶绿体。", "同一块茎见光后变绿，能否由此推断其基因序列发生改变？", "不能。质体分化和基因表达改变已能解释该现象。"]
```

目录计数、搜索索引和知识点页面会随数据重新生成。页面地址和学习记录使用阶段标识与英文术语生成的 ID。调整中文文字和课程顺序可保留记录。如果要修改英文术语，可以在数组第六项填入旧页面地址里的 ID，使原地址继续有效。

## 从一次搜索学习前后端

1. 打开 `lib/course.js`，查看五份 JSON 如何整理为统一课程对象与搜索摘要。
2. 阅读 `app/api/topics.json/route.js`。这个 Next.js GET 路由将摘要输出为 JSON。开发模式下可访问 `/api/topics.json`，静态构建时会生成同名索引文件。
3. 在 `components/shell.jsx` 查找 `fetch`，观察前端如何请求索引、处理加载失败、筛选术语并导航至知识点。
4. 阅读 `app/learn/[id]/page.jsx` 和 `components/reader.jsx`，对照服务端课程读取与客户端自测、收藏交互。
5. 修改 `app/globals.css` 的主题色或布局。样式入口引入 Tailwind，组件可以直接使用其工具类。
6. 进阶练习可以从进度同步开始。切换为 Next.js 服务端部署后，将当前浏览器存储的进度模型迁入数据库，并在写入路由中按登录用户隔离记录。

本版将学习进度和收藏保存在当前浏览器的 localStorage。清理站点数据后会重新开始。首页细胞主视觉和学科版画为 AI 生成的艺术示意图。

开发参考见 [Next.js 静态导出](https://nextjs.org/docs/app/guides/static-exports) 与 [Tailwind CSS 的 Next.js 集成](https://tailwindcss.com/docs/installation/framework-guides/nextjs)。
